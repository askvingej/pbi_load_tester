fetch_top_queries_from_logs(token, cluster_url, database, workspace_id,
    dataset_id, top_n, min_count, sort_mode, exclude_session_prefix,
    date_from, date_to) -> (list[dict], kql_str)

  sort_mode → KQL-sortering:
    "Vanligast körda"       → Count desc
    "Längst duration (p95)" → P95Ms desc
    "Längst duration (avg)" → AvgMs desc
    "Högst CPU-tid"         → AvgCpuMs desc
    "Senast körda"          → LastSeen desc

  KQL summarize: Count, AvgMs, P95Ms, AvgCpuMs (om tillgänglig),
    LastSeen=max(), LastUser=take_any(ExecutingUser)

  Datumfilter:
    | where TimeGenerated >= datetime({date_from})
    | where TimeGenerated < datetime({date_to}) + 1d

  Session-filter: | where not(CleanQuery matches regex @'VAR _Session\s*=\s*"{prefix}')
  Blockera: COLUMNSTATISTICS, COLUMNTRAITS, SYSTEMRESTRICTSCHEMA, $SYSTEM, __XL_
  Rensa: tracking-VARs, [WaitTime: X ms]

  Records: {query, count, avg_ms, p95_ms, cpu_ms, last_user, last_seen}

cluster_queries_by_pattern(): propagerar p95_ms, avg_cpu_ms, last_user, last_seen.

describe_dax_query(dax) -> str:
  LOKAL regex-analys — INGA externa API-anrop.
  import re as _re_local  INUTI funktionen (inte modulnivå _re_dax)
  Identifierar: tabeller ('T'[C]-mönster), aggregeringar (SUMMARIZECOLUMNS etc.),
  mått (kolumnnamn i resultat), filter (TREATAS/IN/datum),
  tidsintelligens, fönsterfunktioner, komplexitet (VARs, EVALUATE-count)

UI: Rensa eh_desc_*-nycklar vid ny hämtning.
    Varaktigheter i sekunder med 1 decimal (ms/1000).
    Varje mönster: körningar · avg sek · p95 sek · senast kördes av user/tid

LAKEHOUSE EXPLORER
────────────────────────────────────────────────────────────────────────────────

Separeras från lasttestaren med 3px #00d4aa-linje.

ANSLUTNING:
  Workspace: GET /v1.0/myorg/groups (Power BI-token)
  Lakehouse: GET api.fabric.microsoft.com/v1/workspaces/{ws}/lakehouses (Fabric-token)

TABELLUPPTÄCKT (🔍):
  1. GET /lakehouses/{id} → properties.oneLakeTablesPath
  2. ADLS Gen2 list: {path}?resource=filesystem&recursive=false (storage-token)
  3. Kolla _delta_log → Delta-tabell eller schema-katalog
  4. Lista ett nivå djupare för scheman
  5. Returnera {schema: [table, ...]}

ANALYS (📊 Analysera + ⏹ Avbryt via session_state["le_abort"]):

  DeltaTable URI: abfss://{ws}@onelake.dfs.fabric.microsoft.com/{lh}/Tables/{schema}/{tbl}
  storage_options: {bearer_token, use_fabric_endpoint:"true", account_name:"onelake"}

  ── Steg 1: Delta-logg metadata (NOLL datainläsning) ─────────────────────────
  get_add_actions(flatten=False) → PyArrow Table med nested structs:
    - null_count.{col} per fil → summera → exakt null_count för hela tabellen
    - min_values.{col} / max_values.{col} → global min/max
  INTE flatten=True (ger inte nested stats). INTE to_pydict() — använd .column().

  _dl_null = {col: total_null_count}   # exakt, alla rader
  _dl_min  = {col: global_min}
  _dl_max  = {col: global_max}

  ── Steg 2: Proportionellt filurval med dynamiskt tak ──────────────────────────
  _sample_ratio    = min(1.0, sample_rows / total_rows)
  _n_files_to_read = max(1, round(n_frags * _sample_ratio))
  Välj filer jämnt spridda: step = n_frags / n_files, indices = [int(i*step) ...]

  Dynamiskt tak per fil (totalt max 500 000 rader):
    _TOTAL_ROW_CAP = 500_000
    _max_per_frag  = max(100, _TOTAL_ROW_CAP // len(_sel_frags))

  ── Steg 3: Kolumnvis läsning ──────────────────────────────────────────────────
  För varje kolumn i varje vald fil:
    _ft  = _frag.to_table(columns=[col_name])       # bara denna kolumn
    _col = _ft.column(col_name)
    if len(_col) > _max_per_frag: _col = _col.slice(0, _max_per_frag)
    del _ft                                           # frigör minne direkt!
  Bygg _col_arrays = {col_name: pa.chunked_array(chunks)}

  VIKTIGT: _stats = [] initieras FÖRE kolumn-loopen
  VIKTIGT: _tbl_nbytes = sum(a.nbytes for a in _col_arrays.values()) EFTER loopen
           if not _tbl_nbytes: används som guard i fallback

  ── Per kolumn ─────────────────────────────────────────────────────────────────
  _arr = _col_arrays.get(col) eller _tbl_pa.column(col)

  null_count: _dl_null.get(col) om Delta-logg OK, annars arr.null_count
  null_pct  = null_count / max(total_rows, 1) * 100

  distinct  = len(pc.unique(arr))
  size_pct  = arr.nbytes / max(_tbl_nbytes, 1) * 100

  Kard% av sample = distinct / max(sample_rows, read_rows, 1) * 100
  Kard% av totalt = distinct / max(total_rows, 1) * 100
  Adaptiva decimaler: >=1% → 1 dec, >=0.01% → 3 dec, annars 5 dec

  Est. total kardinalitet:
    saturation = distinct / max(read_rows, 1)
    if saturation > 0.5: est = distinct, reliable = False  → visa "≥ X,XXX"
    else: est = int(distinct / read_rows * total_rows)

  Exempelvärden: upp till 5 unika icke-null + Delta-logg min/max

VARNINGSGRÄNSER (kardinalitet):
  ⚠️ > 1 000 000: DISTINCTCOUNT kostsam, MEDIAN/PERCENTILE itererar alla rader
  ⚠️ > 700 000:   APPROXIMATEDISTINCTCOUNT(), MEDIAN kostsam, relationer
  ℹ️ > 75 000:    DISTINCTCOUNT/MEDIAN fungerar men märks
  ℹ️ null > 50%:  datakvalitet — EJ prestandaproblem

FILREKOMMENDATIONER (bara om > 100 MB eller > 100k rader):
  Opartitionerad: ✅ ≤1 fil; 🔴 >20 filer avg<1MB; 🟡 >20 filer avg<64MB
  Partitionerad:  per partition, varna om >1 fil AND avg<10MB AND totalt>10MB

KOLUMNORDNING I DATAFRAME:
  Kolumn · Rekommendation · Storlek % · Distinkta (sample) ·
  Kard% av sample · Kard% av totalt · Est. total kardinalitet ·
  Exempelvärden · Null % · Datatyp

  Sorteras på _est_sort (numerisk version av Est. total kardinalitet) DESC.
  to_numeric(..., errors="coerce") för alla numeriska kolumner.
  tips-kolumnen döljs i dataframe men används i varningsexpanders.

TEKNISKA FALLGROPAR
────────────────────────────────────────────────────────────────────────────────

1.  global/nonlocal → [0]-listor eller session_state
2.  Typannoterade modulvariabler utan global
3.  profile_load-mönstret: skriv session_state INNAN widgets
4.  requests json= → ASCII-escapar åäö. Använd data=json.dumps(ensure_ascii=False).encode()
5.  DAX-params lägger INTE till citattecken — hanteras i DAX-texten
6.  get_add_actions(flatten=False) → PyArrow Table med nested structs
    Använd .column(name) + .type.num_fields + [ri][fi].as_py()
    INTE to_pydict() — crash på stora tabeller
7.  deltalake head() finns EJ i v1.x
8.  Tre separata tokens: Power BI ≠ Fabric REST ≠ OneLake Storage
9.  Schema-aktiverade lakehouses: /tables → 400. Använd oneLakeTablesPath + ADLS
10. _re_dax + _TREATAS_RE definieras på modulnivå FÖRE första användning
11. describe_dax_query: import re as _re_local INUTI funktionen
12. _stats = [] FÖRE kolumn-loopen
13. _tbl_nbytes sätts EFTER _col_arrays är byggd; if not _tbl_nbytes: som guard
14. del _ft efter varje fil för att frigöra minne och undvika segmentation fault
15. Est. total kardinalitet är sträng med möjligt "≥ "-prefix — strip vid int()-konvertering:
    int(str(v).replace(chr(8805)+chr(32),"").replace(",","").strip() or 0)
16. Kardinalitet % beräknas mot total_rows (EJ read_rows)
    Kard% av sample = distinct / max(sample_rows, read_rows) * 100
