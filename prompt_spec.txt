Bygg en lokal lasttestar-applikation för Power BI semantiska modeller i Python med Streamlit.
Applikationen körs lokalt via: python -m streamlit run app.py

Beroenden (requirements.txt):
  streamlit>=1.32.0
  requests>=2.31.0
  pandas>=2.0.0
  plotly>=5.18.0

Allt läggs i en enda fil: app.py
En separat fil dax_library.json skapas automatiskt för sparade profiler.

st.radio "Körläge": ["Iterationer", "Tidsbaserat"]

Iterationer:
  number_input: Iterationer (1-5000, default 20)
  number_input: Parallella anrop (1-50, default 3)
  number_input: Fast fördröjning ms (0-10000, default 0)

Tidsbaserat:
  number_input körtid + selectbox enhet (sekunder/minuter/timmar)
  number_input: Max parallella anrop (1-50, default 5)
  selectbox: Trafikprofil

  Funktion next_delay_seconds(profile, elapsed, duration_sec, concurrency) -> float:

  "Vågor (burst + paus)":
    wave = math.sin(elapsed * 2 * math.pi / 30)
    return random.uniform(0.05,0.3) if wave > 0.3 else random.uniform(2.0,6.0)

  "Kontorstider (trappa upp/ner)":
    progress = elapsed / max(duration_sec, 1)
    intensity = progress/0.2 if progress<0.2 else 1.0 if progress<0.8 else (1.0-progress)/0.2
    return max(0.05, 2.0 - intensity*1.8) + random.uniform(-0.1, 0.1)

  "Slumpmässig":
    return random.choice([random.uniform(0.05,0.3), random.uniform(0.5,2.0), random.uniform(3.0,8.0)])

  "Konstant": return 0.05

────────────────────────────────────────────────
DAX-PARAMETRAR (expander under DAX-editorn)
────────────────────────────────────────────────
st.expander "Parametrar" visar antal detekterade platshållare.

Platshållar-syntax i DAX: {{paramnamn}}
Exempel:
  TREATAS({"{{fartyg}}"}, 'Fartyg'[Fartygsnamn])   <- text med citattecken i DAX
  TREATAS({{{ar}}}, 'Trafikdygn'[Ar])               <- nummer utan citattecken

Detektering: re.findall(r"\{\{(\w+)\}\}", dax_text)
Synka session_state["dax_params"] mot detekterade platshållare.

För varje platshållare: selectbox Typ (text/number/date), selectbox Läge, text_input Värden.

Funktion apply_dax_params(dax, params, iteration) -> str:
  Ersätter {{param}} med värdet RAKT AV utan att lägga till/ta bort citattecken.
  Citattecken i DAX-queryn hanteras av DAX-texten, inte av funktionen.

  Exempelresultat:
    TREATAS({"{{fartyg}}"}, ...) + värde "Viberö" -> TREATAS({"Viberö"}, ...)
    TREATAS({{{ar}}}, ...)       + värde "2025"   -> TREATAS({2025}, ...)

  Undantag: date-typ konverterar "YYYY-MM-DD" -> "DATE(yyyy, mm, dd)".

  Normalisering av värden (kritiskt för åäö):
    unicodedata.normalize("NFC", val).strip()
    Ta bort kontrolltecken: "".join(c for c in val if unicodedata.category(c) != "Cc")
    Ersätt typografiska citattecken: \u201c->" \u201d->" \u2018->' \u2019->'

  Lägeslogik:
    "Rotation": values[iteration % len(values)]
    "Fast":     values[0]
    "Slumpa":   random.choice(values)

  Anropas i körloopen INNAN run_dax():
    dax = apply_dax_params(queries[i % n], st.session_state.get("dax_params",[]), i)

────────────────────────────────────────────────
DAX VAR-INJEKTION FÖR LOGGSPÅRNING
────────────────────────────────────────────────
Sker i run_dax() EFTER apply_dax_params.
Normalisera hela strängen: unicodedata.normalize("NFC", dax.strip())

tracking_vars byggs med strängkonkatenation (inte f-strängar med escaped \n):
  "VAR _Session          = \"" + session_tag + "\"\n" +
  "VAR _ImpersonatedUser = \"" + (username or "anon") + "\"\n" +
  "VAR _CorrelationId    = \"" + corr_id + "\"\n"

Fall 1 - börjar med EVALUATE:
  Wrappa: EVALUATE\n{tracking_vars}RETURN\n{kropp utan EVALUATE}

Fall 2 - börjar med DEFINE:
  define_end = dax.index("DEFINE") + len("DEFINE")
  dax = dax[:define_end] + "\n" + tracking_vars + dax[define_end:]

Fall 3 - okänt: prependa kommentar "// session:X user:Y\n"

KQL för analys:
  SemanticModelLogs
  | where QueryText contains "_Session"
  | extend
      Session = extract(@'_Session\s+=\s+"([^"]+)"', 1, QueryText),
      User    = extract(@'_ImpersonatedUser\s+=\s+"([^"]+)"', 1, QueryText)
  | summarize count(), percentile(DurationMs,50), percentile(DurationMs,95) by User, Session

API-ANROP (run_dax)
────────────────────────────────────────────────
Returnerar alltid: (duration_ms, rows, error, correlation_id)

Headers: Authorization, Content-Type: application/json; charset=utf-8, X-PowerBI-CorrelationId

Endpoint:
  POST https://api.powerbi.com/v1.0/myorg/groups/{ws}/datasets/{ds}/executeQueries
  Body: {"queries": [{"query": dax}], "serializerSettings": {"includeNulls": true}}

KRITISKT - svenska tecken:
  json_bytes = json.dumps(body, ensure_ascii=False).encode("utf-8")
  requests.post(url, data=json_bytes, headers=headers, timeout=timeout)
  Använd INTE json=body - det ASCII-escapar åäö till \u00e5 etc.

HTTP 429: max 3 retry med exponential backoff, respektera Retry-After-header.

────────────────────────────────────────────────
VANLIGA FALLGROPAR
────────────────────────────────────────────────
1. global/nonlocal fungerar inte i Streamlit-skript-scope.
   Lösning: listor [0] eller st.session_state.

2. Typannoterade modulvariabler (x: Type = val) kan inte global-deklareras.

3. Streamlit ignorerar value=/index= på widgets med befintlig session_state-nyckel.
   Lösning: skriv till st.session_state["key"] INNAN widgeten renderas.

4. Bakgrundstrådar kan inte uppdatera st.session_state.

5. width="stretch" på knappar. Undantag: plotly_chart/dataframe använder use_container_width=True.

6. nonlocal fungerar inte i nästlade funktioner inuti if-block.
   Lösning: i_counter = [0], i_counter[0] += 1.

7. requests json=body ASCII-escapar åäö.
   Lösning: json.dumps(body, ensure_ascii=False).encode("utf-8") + data= istället för json=.

8. DAX-parameterersättning ska INTE lägga till citattecken.
   Fel: "{{fartyg}}" -> ""Viberö"" (dubbla citattecken)
   Rätt: "{{fartyg}}" -> "Viberö" (ett par, redan i DAX-texten)

9. DEFINE-queries: injicera tracking-VARs inuti DEFINE-blocket.
   EVALUATE-queries: wrappa med VAR...RETURN.
