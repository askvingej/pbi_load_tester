================================================================================
SPEC: Power BI Semantic Model Load Tester + Lakehouse Explorer
================================================================================

Bygg en lokal webbapplikation i Python + Streamlit som kombinerar två verktyg:
1. Lasttestar för Power BI semantiska modeller (DAX via executeQueries REST API)
2. Lakehouse Explorer för att analysera Fabric Delta-tabeller direkt via OneLake

Starta med: python -m streamlit run app.py
Kör lokalt mot Microsoft Fabric/Power BI via Azure CLI-autentisering.
Allt i en fil: app.py. Profiler sparas i dax_library.json.

requirements.txt:
  streamlit>=1.32.0
  requests>=2.31.0
  pandas>=2.0.0
  plotly>=5.18.0
  deltalake>=0.17.0
  pyarrow>=14.0.0

next_delay_seconds(profile, elapsed, duration_sec) -> float:
  Vågor:       math.sin(elapsed * 2π / 30) > 0.3 ? uniform(0.05,0.3) : uniform(2,6)
  Kontorstider: intensity baserat på progress, return max(0.05, 2.0 - intensity*1.8)
  Slumpmässig: random.choice([uniform(0.05,0.3), uniform(0.5,2), uniform(3,8)])
  Konstant:    0.05

────────────────────────────────────────────────────────────────────────────────
DAX-PARAMETRAR
────────────────────────────────────────────────────────────────────────────────

Platshållar-syntax: {{paramnamn}}
  Text:  TREATAS({"{{fartyg}}"}, 'Fartyg'[Fartygsnamn])  -> citattecken i DAX-texten
  Siff:  TREATAS({{{ar}}}, 'Trafikdygn'[År])
  Datum: 'Trafikdygn'[Trafikdygn] >= {{startdatum}}  -> DATE(yyyy,mm,dd)

apply_dax_params(dax, params, iteration) -> str:
  Ersätter {{param}} RAKT AV. Lägger INTE till citattecken.
  Normalisera: unicodedata.normalize("NFC", val).strip()
  Ta bort kontrolltecken. Ersätt typografiska citattecken.
  Auto-detektera typ: om nummer-param-värde inte är rent tal -> behandla som text.

format_value(val, typ):
  number: om värdet matchar ^-?\d+(\.\d+)$ -> returnera rakt, annars citera som text
  text:   f'"{val.replace('"', '""')}"'
  date:   DATE(yyyy, mm, dd)

LAKEHOUSE EXPLORER
────────────────────────────────────────────────────────────────────────────────

# 🗄️ Lakehouse Explorer (separeras från lasttestaren med 3px #00d4aa-linje)

ANSLUTNING (expander):
  Workspace-dropdown: GET https://api.powerbi.com/v1.0/myorg/groups (Power BI-token)
  Lakehouse-dropdown via @st.cache_data(ttl=120):
    GET https://api.fabric.microsoft.com/v1/workspaces/{ws}/lakehouses  (Fabric-token)
    Fallback: /items?type=Lakehouse

TABELLUPPTÄCKT (knapp: 🔍 Identifiera scheman och tabeller):
  1. Hämta oneLakeTablesPath från GET /lakehouses/{id}
  2. Lista toppnivå via ADLS Gen2: {tables_path}?resource=filesystem&recursive=false
     (storage_token med audience https://storage.azure.com/)
  3. Kolla om katalog är Delta-tabell (har _delta_log) eller schema (har underkatalog-tabeller)
  4. Lista ett nivå djupare för schemakataloger
  5. Returnera {schema_name: [table_name, ...]}

KASKAD-DROPDOWNS efter upptäckt:
  multiselect scheman -> multiselect tabeller (format: "schema/tabellnamn")

ANALYS (knapp: 📊 Analysera X tabell(er)):
  Konfiguration: Snabbläge (default 200 000 rader) eller fullständig
  Avbryt-knapp: session_state["le_abort"] = True, kontrolleras per kolumn

  Per tabell:
    1. DeltaTable(uri, storage_options={bearer_token, use_fabric_endpoint:true, account_name:onelake})
       URI: abfss://{workspace_id}@onelake.dfs.fabric.microsoft.com/{lakehouse_id}/Tables/{schema}/{table}

    2. Delta-metadata via get_add_actions(flatten=True) -> PyArrow Table:
       Hitta size-kolumn (nyckel med "size" i namnet)
       Hitta records-kolumn (nyckel med "record" eller "numrow")
       num_files = aa.num_rows
       partition_columns = dt.metadata().partition_columns

    3. Snabbläge: scanner med batch_size, läs tills N rader, slice(0, N)
       Fullständigt: ds.to_table()

    4. Per kolumn: COUNT DISTINCT via pc.unique(), null_count, kardinalitet %
       Kardinalitet % = distinct / total_rows (INTE / read_rows)
       Est. total kardinalitet = distinct / read_rows * total_rows (linjär extrap.)

VARNINGSGRÄNSER:
  Kardinalitet: ⚠️ > 700k | ⚠️ > 1M | ℹ️ > 75k (med DAX-prestandatips)
  Null:         ℹ️ > 50% (datakvalitetsinformation, inte prestandaproblem)

  Fil-rekommendationer (bara om tabell > 100 MB eller > 100k rader):
    Opartitionerad: ✅ om <= 1 fil, 🔴 om > 20 filer avg < 1 MB, 🟡 om > 20 filer avg < 64 MB
    Partitionerad:  analysera per partition, varna om > 1 fil AND avg < 10 MB AND totalt > 10 MB

  DAX-prestandatips per kardinalitetsnivå:
    > 1M: DISTINCTCOUNT mycket kostsam, MEDIAN/PERCENTILE itererar alla rader, undvik som slicer
    > 700k: överväg APPROXIMATEDISTINCTCOUNT(), MEDIAN kostsam, relationer kan vara långsamma
    > 75k: DISTINCTCOUNT och MEDIAN fungerar men märks, överväg APPROXIMATEDISTINCTCOUNT()

RESULTAT PER TABELL:
  4 metrics: Totalt radantal · Storlek MB · Antal filer · Snittfilstorlek MB
  Täckningsprocent: read_rows / total_rows * 100
  st.dataframe sorterad på Est. total kardinalitet DESC
  CSV-export per tabell
  Varningar i expanderbara sektioner med prestandatips

────────────────────────────────────────────────────────────────────────────────
TEKNISKA FALLGROPAR — LÄSES NOGGRANT
────────────────────────────────────────────────────────────────────────────────

1. global/nonlocal fungerar inte i Streamlit. Använd [0]-listor eller session_state.

2. Typannoterade modulvariabler kan inte global-deklareras.
   FEL:  _rate_limiter: RateLimiter = RateLimiter(0)  + global _rate_limiter
   RÄTT: _rate_limiter = RateLimiter(0)  (ingen typannotering)

3. Streamlit ignorerar value=/index= på widgets med befintlig session_state-nyckel.
   Lösning: skriv till session_state["key"] INNAN widgeten renderas, sedan st.rerun().

4. requests json=body ASCII-escapar åäö.
   RÄTT: data=json.dumps(body, ensure_ascii=False).encode("utf-8")

5. DAX-parametrar lägger INTE till citattecken — de ska finnas i DAX-texten.
   FEL:  TREATAS({{fartyg}}, ...)  -> TREATAS(Viberö, ...)    [syntaxfel]
   RÄTT: TREATAS({"{{fartyg}}"}, ...) -> TREATAS({"Viberö"}, ...) [korrekt]

6. DEFINE-queries: injicera tracking-VARs INUTI DEFINE-blocket.
   EVALUATE-queries: wrappa med VAR ... RETURN.

7. get_add_actions(flatten=True) returnerar PyArrow Table, inte dict.
   Använd: aa.column("kolumnnamn").to_pylist() — INTE aa.to_pydict()

8. deltalake head() finns inte i v1.x.
   Använd: dataset.scanner(batch_size=N) + iterera batchar

9. Power BI-token (analysis.windows.net) fungerar INTE mot Fabric REST API.
   Fabric REST API kräver token med audience https://api.fabric.microsoft.com
   OneLake ADLS kräver token med audience https://storage.azure.com/

10. Schema-aktiverade lakehouses: /tables returnerar 400.
    Lösning: GET /lakehouses/{id} -> properties.oneLakeTablesPath, lista via ADLS Gen2.
